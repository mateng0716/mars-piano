## 学习内容

- 初遇钢琴：参考巴斯蒂安幼儿启蒙顺序的六个原创小发现，先黑键、高低音与左右手，再到长短音和白键乐句。
- 乐理探险：保留 19 节短课，基础先行，后段明确作为拓展；点课直接进入。
- 弹一首喜欢的：五首简易教学节选，左/右/双手谱，只按音高顺序推进，可试听全部练习小节。
- 旋律回声：先听再弹，每次两到四颗音，可重听与请求提示。
- 节奏小火车：任意琴键回应原创节奏，感受等拍、长短与休止；不按固定速度倒计时判错。
- 弹音探险：一分钟识谱游戏，局部颜色、礼花和音效反馈，本机记录。

琴键覆盖 C2–C7，使用 Splendid Grand Piano 采样。无数值滑杆调宽、↕ 拖动调高，C 键保持极浅底色；宽高与原游戏记录保留。触屏横移门槛为 12px、方向比为 1.15（`app.js` 中可调），不吞掉首个有效拖动。双手谱优先保证两行完整、等比缩放。

## 配合电钢琴

右上角“连接电钢琴”由家长选择：支持的浏览器可接 USB/MIDI；也可用麦克风听单音。麦克风只在本机分析，不上传、不保存录音。示范期间忽略答案；回首页、后台和关页会停止麦克风，回来后主动重连。MIDI 设备断开后保留重连入口，屏幕琴键一直可用。

麦克风反馈受琴声、环境与设备影响，不支持和弦/双手同步评估，不评手型、力度、最后一音保持时长。新玩法和现有课程共享输入。浏览器支持、连接数据流模拟、合成声音检查与真琴体验分别记录，不互相替代。

## 检查与交付

```bash
node --check app.js
node --check piano-input.js
node --check piano-adventure.js
node scripts/check_learning.js
```

其余 `course-data.js`、`music-data.js`、`lesson-visuals.js` 同样运行语法检查；交互使用 headless WebKit/Chromium，覆盖 1194×834、768×1024、390×844。真实 iPad 触控、真琴 USB/MIDI 与麦克风、亲子听感须单独验收。

`index.html` 依次加载现有三个数据/绘图脚本、`app.js`、`piano-input.js`、`piano-adventure.js`。`version.json` 与入口版本常量同步，主页 ↻ 可刷新；已有主屏幕入口保持 `/`。图标换新是否立即反映由 iPadOS 决定。
