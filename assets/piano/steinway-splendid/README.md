# Splendid Grand Piano samples

Source: [sfzinstruments/SplendidGrandPiano](https://github.com/sfzinstruments/SplendidGrandPiano). Its maintainers describe the underlying AKAI Steinway piano recordings as public domain. This project uses the `Mp` sample layer for the C2–C7 keyboard and converts the original FLAC recordings to AAC/M4A at 160 kb/s for browser playback. Notes without an exact source recording are pitched from the nearest recorded note with Web Audio.

`Steinway` identifies the recorded instrument described by the source project; this family prototype is not affiliated with or endorsed by Steinway & Sons. The [source repository](https://github.com/sfzinstruments/SplendidGrandPiano) also contains SFZ mappings and credits. Import steps are in `scripts/import_splendid_samples.py` at the project root.
