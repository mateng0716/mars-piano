# Blue piano family artwork · 2026-11-13

The user requests a bright blue family-app direction consistent with CC’s English and rejects thick offset-shadow pseudo-3D buttons. These original raster illustrations were created with the built-in image generation tool, not with CSS extrusion.

- `blue-studio-hero-source.png`: an edit of the existing `mars-and-chase.webp` character reference, preserving the familiar boy / puppy identities and replacing their action with a blue piano scene. Browser derivative: `blue-studio-hero.webp` (1100 px wide, alpha preserved).
- `blue-note-source.png`: a newly generated round blue quarter-note and yellow star. Browser derivative: `blue-note.webp` (256 px). Used in pre-staff discoveries and revealed echo notes; register arrows still represent high/low.
- `blue-music-atlas-source.png`: newly generated 3×2 equal-cell atlas, keyboard / music book / grand piano / headphones / train / note. Browser derivative: `blue-music-atlas.webp` (960×640). CSS backgrounds use 300%×200% and six positions. The soft white matte blends into the cream cards with `mix-blend-mode:multiply`; no app CSS shadow is used.
- `../icons/piano-m-blue-source.png`: a recolor/edit of the prior M piano icon to bright royal/sky blue and ivory. 180/192/512 PNG exports are the current manifest and Apple touch assets. Previous purple icons remain for recovery.

All source PNGs remain intact. WebP and size-specific icons are resized/encoded derivatives from the source, not repeated lossy transcodes. The family reference image and the Nunito font/OFL were read/copied from the existing local projects; no English-site files or private configuration were changed. Generated images and browser checks are not physical-device or child/parent acceptance.
